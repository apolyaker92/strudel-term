## Why AGPL

It depends on [Strudel](https://codeberg.org/uzu/strudel) and superdough, both
AGPL-3.0-or-later, and links against them at runtime. That makes this a
derivative work, so it carries the same licence.

In practice: use it however you like, and if you distribute it or run it as a
network service, the source has to be available under the same terms.

`node-web-audio-api` is BSD-3-Clause and is not affected by that.
